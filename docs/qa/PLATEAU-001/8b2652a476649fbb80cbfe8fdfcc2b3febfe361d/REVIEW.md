# Фактическая дыра в вырезе маски

Source8b2652a476649fbb80cbfe8fdfcc2b3febfe361d. Предыдущее исправление угловых торцов не устраняло отсутствие внутренних поверхностей выреза внутри выступающей маски. Теперь границы прохода пересекаются с объёмом маски (тетраэдры ячеек) и создают недостающий пол/стены.

Важная проверка:171 выборка на новых поверхностях вне исходной земли. Без добавленных поверхностей первый луч проходил23.45м, с ними упирается через0.5м.622 новых треугольника. Before/after — одна камера в одной сцене, отключена/включена только новая поверхность. В before видна сквозная дыра, в after закрытая стена. Эти кадры и лучи доказывают конкретное исправление, а не общее визуальное одобрение.

Капсула проходит вверх и обратно по40467 конечным локальным треугольникам. Финальные lab TypeScript и root build PASS; промежуточная ошибка типизации пустого массива planes исправлена явным типом, runtime не менялся. Новая поверхность использует тот же shader rock; polygon offset исключает мерцание на перекрывающихся старых участках. Полная синхронизация всех оболочек остаётся отдельной задачей.
