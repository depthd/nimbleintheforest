## Кадры The Long Dark

Скриншоты из публичных материалов Hinterland и сообщества, которые были под рукой во время работы. Использовались для сравнения форм, рельефа и маршрутов. У части локальных копий сохранилось только рабочее имя файла.

- Ash Canyon, отдельные скальные выходы и разрывы между ними. [Переход по мосту](the-long-dark/ash-bridge.jpg) · [переход по бревну](the-long-dark/ash-log.jpg) · [деревья в ущелье](the-long-dark/ash-trees.jpg) · [панорама](the-long-dark/ash-vista.jpg) · [страница Ash Canyon у Hinterland](https://www.thelongdark.com/survival-update-december-2020/).
- Timberwolf Mountain, лесная поляна и глубина обзора сверху. [Поляна](the-long-dark/timberwolf-clearing.jpg) · [страница снимка в Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=576931658) · [кадр с высоты](the-long-dark/timberwolf-summit.jpg) · [обсуждение района на форуме Hinterland](https://hinterlandforums.com/forums/topic/36786-timberwolf-mountain-and-the-downed-aircraft/).
- Вид на массив из леса, сохранённая копия Steam. [Кадр](the-long-dark/steam-exact.jpg).

Исходные ZIP из первой передачи и из вложения с девятью кадрами были недоступны при сохранении. Список этих девяти и их заметки сохранились в [первоначальной передаче](../HANDOFF.md#референсы-и-исследование).

## Восстановление черновиков

Исторические скрипты сохранены как текстовые записи, включая зависимости от среды и журналы ошибок. [Первая боковина](work-notes/mountain-review/) · [стык снега](work-notes/mountain-polish/) · [три яруса](work-notes/mountain-stack/) · [финальная серия боковин](work-notes/mountain-wall/).

Из сохранившихся скриптов восстановлены два набора исходных правок. [Ранняя версия из `change.py`](work-notes/reconstructed/outcrops-pilot.patch) · [следующая версия из `change.py`, `iterate.py` и `shoulders.py`](work-notes/reconstructed/outcrops-round2-with-shoulders.patch). Оба патча применяются к `8fd1a125003898d0b754f69ee898a0d237b5f293` по отдельности. Это восстановленные правки. Второй патч собрался и отрисовался в Chromium. Число скал и осыпей на всех ярусах совпало с прогоном `round2`, а сам кадр отличается. [Кадр после восстановления](work-notes/reconstructed/checked-wall.jpg) · [параметры и счётчики](work-notes/reconstructed/checked-capture.json).

```bash
git worktree add --detach ../nimble-mountain-draft 8fd1a125003898d0b754f69ee898a0d237b5f293
git -C ../nimble-mountain-draft apply "$PWD/docs/qa/PLATEAU-001/history-2026-11-20/work-notes/reconstructed/outcrops-pilot.patch"
cd ../nimble-mountain-draft
npm ci
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

[Открыть гору](http://127.0.0.1:5173/experiments/plateau/mountain.html).
