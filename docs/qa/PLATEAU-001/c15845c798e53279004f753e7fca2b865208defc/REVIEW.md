# Три вида внешней кромки по выбранным интерпретациям

Source `c15845c798e53279004f753e7fca2b865208defc`. Пользователь выбрал 1 и 3 из рисунка интерпретаций, разрешил 2 как вариацию и попросил реализовать сразу все три.

- **1 · angular** — сплошная ломаная, прямые отрезки и V-впадины.
- **2 · stepped** — угловатые куски с закрытыми крутыми ступеньками.
- **3 · arcs** — округлые выпуклые подъёмы с острыми стыками, без округлого дна впадин.

[Сравнение кромки](comparison.png) — верхние части реальных снимков с одной камеры, собранные в браузере; это не генерация изображения и не линия поверх старой геометрии. Полные кадры: [1](angular-front.png), [2](stepped-front.png), [3](arcs-front.png). В этом фронтальном диагностическом виде показана **только внешняя маска, верх и остальная гора скрыты**, чтобы площадка позади не закрывала кромку.

Со всей геометрией, с верхом и проходом: [1](angular-context.png), [2](stepped-context.png), [3](arcs-context.png). На переходе к прежнему ровному верху видны грани соединяющей полосы; её форму также следует оценить. Это отдельный пробный стенд, не публикация сайта.

Включение: `experiments/plateau/wedge-ascent.html?rim=angular` / `rim=stepped` / `rim=arcs`. По умолчанию flat, тупой торец и без скал/снега. В UI есть ссылки 1/2/3; seed задаётся через rimSeed, по умолчанию 128719.

Для Клода: новый wedge-rim.ts берёт фактический конечный nose из buildWedgeAscent и разбивает его по длине на неравные куски. Пики, стыки и концы ступенек вставляются в треугольники секущими плоскостями; иначе старая сетка сглаживала бы вершины. Координаты общих границ проходят одно отображение. Размеры/наклоны/глубины/высоты/ширина ступенек детерминированы seed и вынесены в rimSettings. Дуги аппроксимированы 16 отрезками на кусок. Ступенька имеет ширину 0.18 м, а не математический разрыв: это крутая перемычка с высотой 2..4 м, без отверстия.

**Меняется внешний силуэт и узкая соединяющая полоса верха/верх маски.** Сохранить всю показанную верхнюю поверхность при изменённой высоте её внешней границы невозможно, поэтому не утверждать, что весь верх прежний. Исходные height arrays не тронуты. Основная площадка, E, проход, старый склон, восстановленная земля и нижняя граница сохраняются; ниже 65 м отображение тождественно. У стен вариация затухает до нуля. Принятые функции поперечного профиля не переписаны; в изменённой внешней полосе верх маски локально следует новой высоте края. Вектор толщины/утопления торца вне затухания сохранён с погрешностью Float32 менее 0.05 мм.

rim.json: все три вида воспроизводятся с одним seed, меняются с другим, проходят проверки прямых/выпуклых дуг/ступенек. Исходная основа не мутируется, защищённые массивы plateau/interior/flank/restored совпадают по хешу, E/attachment/концы фиксированы. Поле protectedHashes в отчёте содержит базовые хеши всех исходных мешей для справки; strip и underside намеренно отмечены changed и не объявлены неизменными.

Покрытие рёбер каждого конечного варианта с допуском 0.5 мм, typecheck, build и проверка трёх UI-переключателей/режимов вида в браузере — PASS. Это проверка плоского стенда, не художественная приёмка. Рельефные комбинации и привязка скал к новой кромке этим QA не подтверждаются. Генератор скал не менялся, в этой пробе отключён; физика, пещера, общая игра, режим 2 прохода и сайт не менялись. Публикации нет. Ждать оценки форм пользователем.
