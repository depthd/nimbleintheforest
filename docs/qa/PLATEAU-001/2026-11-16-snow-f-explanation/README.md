## Исправление прежнего объяснения

На выбранном центральном срезе **нет длинного прямого наружного торца** ни у эталона, ни у «дуг». Высота края над фактическим каменным nose в обоих случаях около **2.5 м**. Видимая разница здесь — зазор под основной снежной полосой и незамкнутые концы снега. Например, за 6 м до края расстояние между нижней линией снега и камнем около 2.697 м. Это **воздух, а не лишняя толщина самого снежного слоя**.

В прежнем ответе я слишком широко перенёс вывод о длинной прямой стенке и увеличенной толщине на выбранный центральный срез дуг. Для этого среза такая формулировка неверна. Увеличение высоты края действительно зарегистрировано в **других местах всего участка**: `../ffa4079e8707073bf573240c43e3622cb6de8ad5/arcs.json` содержит maxSupportLiftM около 4.407 м. Это максимум по участку, не измерение в показанной плоскости.

Нижняя правая маленькая схема явно помечена «схема по коду», «не дополнительный разрез». Она иллюстрирует конструкцию `profile()` при высоте 2.5 м плюс уже записанный максимум дополнительного подъёма: четверть окружности R2 сверху, нижнее закругление R0.5, а между ними прямой отрезок. Она не утверждает существование конкретного дополнительного сечения в этом месте. Связь этой стенки с основной серой полосой на кадрах помечена **предположением**: попиксельного определения видимых поверхностей не выполняли.

Нижний левый рисунок повторяет реальные линии выбранного среза дуг и добавляет пунктир прежнего каменного верха из эталонного разреза. Он показывает установленное по коду рассогласование: `base()` и floor-guard читают исходную `upper`, а nose поступает от новой кромки. Геометрия/код не исправляются.

## Файлы и воспроизведение

- `draw.py` читает только существующие SVG/JSON, проверяет условия сравнения и строит `explanation.svg`, `index.html` и `figure-data.json`. Заново гора не генерируется, сцена не запускается.
- `figure-data.json` хранит ссылки на входные файлы, их SHA256, величины для проверки подписей и явную поправку к объяснению.
- `render.cjs` открывает **только созданную объясняющую HTML-страницу**, без WebGL-сцены, и сохраняет её как `explanation.png`. Это снимок документа, не новый кадр горы.

Из корня checkout:

```bash
python docs/qa/PLATEAU-001/2026-11-16-snow-f-explanation/draw.py
node docs/qa/PLATEAU-001/2026-11-16-snow-f-explanation/render.cjs
```

Для `draw.py` достаточно стандартной библиотеки Python. Для `render.cjs` используются доступные Playwright и `/usr/bin/chromium`; локальный порт5255 обслуживает только документ и закрывается после рендера. PNG осмотрен на подписи, цвета, стрелки и одинаковый масштаб. Новый игровой QA, build, публикация сайта, merge или правка геометрии не выполнялись. Эталон F остаётся эталоном.
