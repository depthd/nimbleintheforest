# Материалы локальной пробы, остановленной по просьбе пользователя

`first-trial/` содержит четыре кадра и отчёт Chromium **первой** пробы. После неё исходники менялись. У коммита WIP готовой съёмки и завершённого QA нет. Имя каталога указывает на сохранённый снимок, а не на SHA кадров.

`mountains-handoff.zip` — самостоятельный пакет для передачи другой модели, 20,8 МБ. Начинать с `00-ПРОЧТИ-СНАЧАЛА.md`. В архиве код, история, заметки, критерии и ключевые кадры. Локальные файлы внутри совпадают с коммитом WIP. Полная история остальных снимков доступна в GitHub.
