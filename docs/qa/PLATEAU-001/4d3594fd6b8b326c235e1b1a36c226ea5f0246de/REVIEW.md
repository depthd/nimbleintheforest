# Крутой цельный профиль, плавный переход

Source `4d3594fd6b8b326c235e1b1a36c226ea5f0246de`. Стенд: `experiments/plateau/wedge-ascent.html?nose=blunt&kind=flat&rocks=0`.

Пользователь не принял прежние полочку/скругление и S-образный эскиз с большим уходом вправо. Последний крутой эскиз признал пределом резкости, попросил мягче и поручил переделать. Изменён сам профиль низа, а не только скругление угла.

- [Разрез](section.png) — реальные конечные треугольники; одинаковый масштаб осей. Оранжевым новая верхняя часть профиля.
- [Спереди](front.png), [сбоку](side.png), [общий вид](general.png) — прежние камеры/свет, без камней и шумового рельефа.
- [Предыдущий разрез](../792332515b76c8dbf9af908b463d4570432b00dc/section.png) для сравнения.

Для Клода: `roundTipCorner` и `undersideDepth` удалены. Общая `undersideSection` задаёт глубину и смещение внутрь одновременно. Вместо радиуса sqrt(t) возле носа используется интегрированная скорость смещения внутрь по глубине: начало направлено вдоль торца, середина идёт круто вниз/внутрь, конец возвращается к направлению сохранённой дуги. Скорость меняется через smoothstep, без горизонтального участка или обратного хода. 4 м / 0.5 м снова являются фактическим концом прямого торца, и дуга продолжает его направление. Толщина/утопление по-прежнему функции положения, без шума и затухания.

**Меняется значительная верхняя часть низа.** Ранний возврат к первому прежнему ряду был причиной полки; теперь возвращение в t=5/6 (ряд 20/24). Начиная с этого ряда старые значения/шаг рядов точные, нижнее примыкание прежнее. Изменённая часть содержит дополнительные половинные ряды, чтобы поворот граней был постепенным. Оба построителя используют одну функцию, далее работают прежние обрезки скрытых частей/прохода.

В profile.json проверены все сечения канонического края плоской фикстуры: глубина/смещение монотонны, минимум спуска на 1 м внутрь около 1.192 м (нет полки), максимум поворота соседних дискретных отрезков около 5.12°. Направления у торца и сохранённой дуги совпали с погрешностью численной проверки порядка 1e-9. Это проверки плоского прототипного профиля, не художественная приёмка и не утверждение о всех гранях после обрезки у прохода.

Защищённые SHA-256 высот, верха/полосы, E, верхнего носа, нижнего примыкания и прохода совпадают с предыдущими пробами. Покрытие рёбер конечной сцены с допуском 0.5 мм, прежние prototype/ascent тесты, typecheck и build PASS. Визуальная оценка ожидается.

Пещера, общая игра, физика, режим 2 и публикация не затронуты. Облицовка в тупой пробе отключена, её лучи на новой форме ещё не проверены. Старые sharp-варианты сохранены. Прежние материал/освещение, нижний стык со старым склоном и его гранёность не переделывались. Остановиться для оценки формы.
