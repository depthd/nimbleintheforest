## Какая гора нужна

Гора — отдельный объект со своими маршрутами. Сверху живое плато с рельефом, деревьями и местом для исследования. Композиция этой пробы — широкое основание, среднее плато на нём и маленькая вершина. К конкретной высоте и форме отдельных камней можно вернуться по кадрам.

Оценка пользователя по кадрам:

- Стена выглядит плоской, когда весь её край образует одна наклонная плоскость. В нужном варианте край складывается из камней разной формы и размера, с выступами, трещинами и углублениями.
- Важен баланс. Варианты 02, 05, 10 и 11 дают глубину и разнообразие, оставляя достаточно крупных спокойных граней. № 10 ближе всего к тому, что пользователь имеет в виду по The Long Dark.
- У края снег пока местами читается как линия одинаковой толщины. В референсах видны разные объёмы и освещённые плечи. Белые стыки между камнями можно принять за снег внутри трещины. На одних камнях снег ложится сверху, другие трещины остаются тёмными.
- Промежуточная объёмная боковина воспринималась как прогресс. Позднее пользователь снова отметил заметные стыки, местами резкие и угловатые формы и в итоге попросил отложить работу. Положительная оценка референсов относилась к изображениям.

На последней сборке у входа появился заметный выступ и тень под ним. На общем плане длинная снежная кромка снова объединяет многие скалы в стенку. Это наблюдение по кадрам, а точный следующий подход остался открытым.

## Как открыть любую версию отдельно

В локальном клоне команды ниже открывают последний вариант в отдельной папке. Для другого варианта подставить полный SHA из таблицы.

```bash
git fetch origin refs/heads/task/PLATEAU-001-rock-masses
git worktree add --detach ../nimble-mountain-review 5a6981b46fb8608f2e662b76c8b1747cfb855ed5
cd ../nimble-mountain-review
npm ci
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

- [Гора, три яруса](http://127.0.0.1:5173/experiments/plateau/mountain.html) · [один ярус](http://127.0.0.1:5173/experiments/plateau/mountain.html?tiers=1). У версий до трёх ярусов `mountain.html` открывает прежнюю одноярусную сцену. Последняя сцена проверялась в Chromium с камерой. Игровое прохождение персонажем в этой сцене не проверялось.
- [Старая маска](http://127.0.0.1:5173/experiments/plateau/) · [стенд кромки и ухода стены в подъём](http://127.0.0.1:5173/experiments/plateau/wedge-ascent.html) · [отдельная проба F](http://127.0.0.1:5173/experiments/plateau/wedge-snow.html?variant=F). Для ранних коммитов стенд должен существовать в выбранной версии.
- Для старых архивных веток сначала сделать `git fetch origin refs/heads/archive/mountains-2026-11-10-failed` или `git fetch origin refs/heads/archive/mountains-2026-11-10-landmarks-deferred`. После этого можно создать worktree на SHA той ветки. Старая генерация открывается через [`experiments/mountains/`](http://127.0.0.1:5173/experiments/mountains/?seed=42).

В подборке есть локальные промежуточные пробы без отдельного коммита. У них сохранены кадры, параметры съёмки и, где нашлись, исходные скрипты правок. Для двух ранних наборов боковины из этих скриптов собраны [патчи на базу `8fd1a12`](history-2026-11-20/README.md#восстановление-черновиков). Их соответствие сохранённым кадрам помечено отдельно.
