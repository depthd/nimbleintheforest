# Все три кромки с рельефом и скалами

Source `c1921993c3f470d086a0921ffe3b2d9e41df4350`. Пользователь прямо попросил добавить скалы и рельеф ко всем трём пробам. Геометрия самих кромок/seed в этом шаге не переделывалась.

Стенд: `experiments/plateau/wedge-ascent.html?rim=angular|stepped|arcs&kind=chaotic&rocks=1`. Имена вариантов: 1 — ломаная; 2 — ступеньки; 3 — дуги с острыми стыками. По умолчанию теперь chaotic и облицовка; явный flat&rocks=0 сохраняет прежний контроль.

На этих кадрах показана **вся геометрия, включая верх**, а не только маска. Сравнение собирается из реальных снимков, не из генерации изображения. В UI переключатель скал активен; голый диагностический вид «Спереди» по-прежнему скрывает верх и облицовку, остальные виды восстанавливают выбранную облицовку.

Для Клода: buildWedgeRocks получает shownCut после применения выбранного rim. Добавлен surfaceRoof в wedge-rocks.ts — быстрый вертикальный поиск по фактическим конечным треугольникам plateau/strip. Старый sampleGrid верхней сетки не отражал впадины/ступеньки нового края, поэтому применять только его для запаса камней до верха было неправильно. Guard использует фактический верх; для внешних стен вне его проекции сохраняется прежний ограничитель по исходной верхней сетке. Отсутствие показанного верха не удаляет облицовку стены. Дополнительно грани камней и снега целиком пересекаются в проекции с гранями верха; минимальный линейный запас проверяется на каждом полученном полигоне, поэтому узкую впадину нельзя перекрыть между безопасными точками привязки. Режимы без rim сохраняют прежний grid guard. RockSkin, рисунок камней, снежные подушки и их seed не переделаны.

Все три комбинации chaotic/blunt/rim прошли проверку покрытия рёбер с допуском 0.5 мм. В dressing проверены независимые горизонтальные лучи привязки и вертикальные лучи верха; ошибка поиска фактического верха порядка 1e-14 м. Применение облицовки не меняет массивы основы по SHA-256. Минимальный запас проверенных вершин и центров граней до фактического верха: angular ~0.809 м, stepped ~0.908 м, arcs ~0.830 м (minRenderedTopClearanceM). Выступ стен в проход ~0.8 м с каждой стороны, центральный коридор открыт. В тесте отдельно есть грань, пересекающая маленький участок верха при безопасных вершинах и центре, и случай внешней стены без показанного верха над ней. Полный guard проверяет наложение плоских граней; независимый тест дополнительно проверяет вершины/центры и вертикальные лучи. Это не полный игровой тест движения/столкновений.

Внешних блоков 1890 / 1874 / 1908 соответственно, на стенах по 242. Из-за защиты верха некоторые целые блоки отбрасываются; местами возле кромки остаётся видимая маска. Слоистость существующего генератора/снега не менялась. Художественная оценка ожидается по снимкам, не объявляется PASS по числам.

Build/typecheck и браузерная проверка трёх режимов, переключателя, ссылок и одинаковых камер — PASS. Исходные формулы профиля/трёх кромок, основной верх/E и проход не переделывались. Пещера, физика, основная игра, режим 2 прохода и сайт не менялись; публикации нет. Остановиться для оценки кадров.
