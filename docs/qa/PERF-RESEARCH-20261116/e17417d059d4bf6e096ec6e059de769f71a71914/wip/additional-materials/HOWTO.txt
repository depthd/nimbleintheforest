Начать с report/report.pdf или report/report.html. Исходные числа — results/,
сводные CPU/GPU/попиксельные CSV — report/. Варианты не объединены.

База: e17417d059d4bf6e096ec6e059de769f71a71914
Все экспериментальные SHA — report/versions.json. Их исходники — в локальном
experiments.bundle и отдельных patches/*.patch (только src, без координационных карточек).
Ничего не отправлялось на GitHub, не мержилось и не публиковалось.

Главный результат: scoped-reader снега улучшает настоящую ходьбу в метели
без изменения данных. Thermal.aggregate экономит немного времени подсистемы,
но ускорение всего кадра не подтверждено. Третья приоритетная гипотеза —
погодный полный refresh снега в Worker; реализации и процента выигрыша пока нет.
Аппаратной видеокарты в среде нет, FPS игрока не измерен.

Воспроизведение (пустая Linux-папка с распакованным архивом):

  export RESEARCH_ROOT="$PWD"
  export CHROMIUM_PATH=/usr/bin/chromium
  mkdir -p results baseline builds
  git clone https://github.com/depthd/nimbleintheforest.git repo
  git -C repo fetch ../experiments.bundle 'refs/heads/*:refs/heads/*'
  git -C repo switch --detach e17417d059d4bf6e096ec6e059de769f71a71914
  (cd repo && npm ci && npm run build)
  git -C repo archive e17417d059d4bf6e096ec6e059de769f71a71914 | tar -x -C baseline
  ln -s ../repo/node_modules baseline/node_modules

В облаке Playwright уже установлен. Иначе установить его в отдельный tooling/:

  npm install --prefix tooling --no-save --no-package-lock playwright
  export NODE_PATH="$RESEARCH_ROOT/tooling/node_modules"

Использовались Node 24.22.1, npm 11.9.0, системный Chromium 156.0.8078.79.
Версии game dependencies закреплены package-lock.json базы.

Протоколы:
- survey.cjs: штатный RAF, 20 кадров на сцену; p95/p99 в такой выборке слабые.
  Исторический первый spawn сохранён отдельно как 80-кадровый partial; он не
  получен стандартным коротким survey. Поле readyMs того partial не использовать.
- cpu-survey.cjs: graphics warmup=0 и render отключён; время игры управляемое.
  Это не FPS. 900 кадров по умолчанию; настоящая ходьба — N=1200 и *-walk.
  Старые forest/blizzard без суффикса используют teleport-проход для стриминга.
- paired-render.cjs: замороженная production-сцена, runtime-патчи, последовательно
  render/readPixels и GPU query. Исходниковые эквиваленты имеют свои SHA/сборки.
  Нельзя считать эти runtime-пробы замером FPS каждой бинарной сборки.
- Отключения no-*-diagnostic только измеряют стоимость категорий; не предлагаются
  как оптимизация. shadow1536 — явный компромисс качества, не скрытый параметр.
- discarded-unsynchronized/ содержит исключённые попытки без надёжного GPU-барьера.
  Ни одна таблица отчёта не использует их времена.
- Общий результат двух рекомендуемых CPU-проб не измерялся. Выигрыши не складывать.
- Скрипты принудительно используют SwiftShader. Для целевой карты нужен отдельный
  протокол без этих flags с повторной записью фактического renderer и условий.

Python make-report.py требует numpy/Pillow для сравнения RGBA и изображений.
CPU profiles можно открыть в Chromium DevTools. Полные browser traces не снимались.
Размеры/положение камеры и настройки — в JSON каждого GPU-прогона.

Отчёт не является разрешением на merge или выпуск. Переносить выбранные src-патчи
в собственную задачу и проверять точный итоговый SHA, включая целевую видеокарту.
