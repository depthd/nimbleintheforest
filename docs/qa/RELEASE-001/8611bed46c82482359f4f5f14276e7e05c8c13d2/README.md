## Ограничения и неуспешные прогоны

Исходный e2e.cjs с обычным render loop: прошли подбор, перила, плед, печь/тепло/сквозняки, дерево, лунка/вода, дверь, еда, бросок, костёр, провал под лёд, охлаждение и 17 укрытий. **Не прошли** «pot of snow boils on the stove» и «no page errors» (ресурс 404; URL этот тест не сохраняет). Полного PASS нет.

Исследовательский повтор с уменьшенной отрисовкой на baseline и кандидате дал другие каскадные сбои. В trace котелок вообще не был экипирован/поставлен (placed=false, pinned=null), поэтому этот прогон не доказывает дефект нагрева. Длинная последовательность не изолирует состояние и использует неоднозначный equip по типу с последующим toggle equip. Причина первоначального одиночного сбоя кипячения окончательно не установлена; нельзя объявлять его исправленным или доказанно унаследованным. baseline-reduced-render.log и e2e-trace.log — диагностические данные, не чистое A/B доказательство.

Первый movement/world-snow запуск не нашёл Playwright bundled browser. Повтор world-snow с системным Chromium и исходный survivor-avatar превысили 180-секундный таймаут холодного запуска под параллельной нагрузкой. Полный world-snow browser PASS не получен. Полноразмерный повтор avatar был остановлен после нескольких поз и заменён указанным выше изолированным прогоном; это явно более узкая проверка.

Среда: Linux, Node v24.22.1, Chromium 156.0.8078.79, SwiftShader, 4 CPU quota. CI использует Node 22. Аппаратный FPS, мобильные устройства и художественная готовность не подтверждены. Топор/кисти и часть анимаций остаются прототипами по исходным контрактам HANDS-001/002.
