# Подготовка стартовой зоны (PERF-002)

После создания мира и установки снега игра завершает ближайшую геометрию рельефа,
готовит исходную позу и оборудование, вызывает `WebGLRenderer.compileAsync`,
затем действительно отрисовывает четыре направления около точки появления,
интерьер дома и исходный вид. Экран загрузки остаётся видимым до завершения.

После каждого прохода WebGL2 fence опрашивается асинхронно, без `gl.finish` в
рабочем коде. Ожидание ограничено 15 секундами на проход: драйвер, не сигнализирующий
fence, не может навсегда удерживать загрузку. Истечение этого предела не является
гарантией полного завершения GPU-работы. Потеря контекста вызывает ошибку запуска.

Прогрев не шагает физикой и не продвигает игровое время. Используется отдельная
камера, игрок не телепортируется. После прогрева сбрасываются накопитель физики
и часы кадра, чтобы длительность загрузки не превращалась в догоняющий шаг.
Руки, запись диагностики, графические настройки и дальности сохранены.

Это подготовка уже созданной ближайшей сцены, не предзагрузка всего мира.
Обновление леса/дальних чанков при путешествии остаётся прежним. Новые источники
света, появившиеся звери, экипировка и новые локации могут требовать новых ресурсов.
Снижение постоянной нагрузки на GPU и устранение всех причин подёргиваний эта
задача не обещает. Время загрузки увеличивается, особенно на программном WebGL.

## Проверки и воспроизведение

```sh
npm run build
node tests/startup-warmup.cjs
CHROMIUM_PATH=/usr/bin/chromium node tests/startup-browser.cjs /tmp/startup-results.json
```

Браузерная проверка открывает два холодных контекста с seed 42: `warmup=0`
отключает только графический прогрев для сравнения, обычный запуск включает его.
Оба варианта завершают геометрию после установки снега. RAF при замере отключён;
игровой мир не симулируется. После загрузки измеряются четыре направления дважды,
включая синхронное ожидание GPU **только в тесте**. Сравниваются состояния мира,
наличие рук/диагностики, прирост числа программ и ошибки JavaScript.

Это изолированный замер стоимости первых отрисовок, не FPS движущегося игрока.
На целевой видеокарте нужно дополнительно сравнить первые 30–60 секунд игры.

## Замер 10 ноября 2026

Chromium/ANGLE SwiftShader, 320×180, два отдельных холодных контекста, seed 42.
Без прогрева первые четыре направления создали 37/4/0/3 новых программы и заняли
5552/4416/129/226 мс. С прогревом: 0/0/0/0 новых программ, 37/16/24/23 мс.
Графическая подготовка заняла 28,5 с; готовность API после начала навигации —
27,2 с без неё и 52,5 с с ней. Это числа программного рендера, не прогноз для GPU.

Время мира (46800), позиция игрока, 319 тел, 2100 коллайдеров, инвентарь и 16242
изменённые снежные ячейки совпали. Новых программ не возникло и во втором проходе,
но в нём был выброс 1882 мс, источник которого данным тестом не установлен.
Поэтому результат подтверждает перенос компиляции/первой подготовки на экран
загрузки, а не полное устранение длинных кадров. Данные — в startup-results.json
локального QA точного SHA; ошибки JavaScript отсутствовали.
