# Боковина у подъёма

[Контактный лист с одной камеры при сиде 42](walls-seed42.png). Верхний ряд — округлые блоки 4, 7 и 10. Нижний ряд — угловатые глыбы 5, 8 и 12. Разрешение каждого исходного кадра 800 × 450. [Исходные кадры, замеры кадра и покрытия снегом](../integration/final-walls/).

Чтобы открыть срез в движке, запустите `npm run dev -- --host 127.0.0.1 --port 5173` в корне рабочей копии. Селектор семейства, пресета и сида расположен в панели сцены. [Исходная стенка](http://127.0.0.1:5173/experiments/plateau/mountain.html?view=wall) · [Семь округлых блоков](http://127.0.0.1:5173/experiments/plateau/mountain.html?wall=rounded&preset=1&seed=42) · [Восемь угловатых глыб](http://127.0.0.1:5173/experiments/plateau/mountain.html?wall=angular&preset=1&seed=42).

## Геометрия округлых блоков

| Блоков | Треугольников в скале и снегу вместе | Максимальная ширина блока при ширине стенки 100 | Минимальный просвет до края подъёма |
| ---: | ---: | ---: | ---: |
| 4 | 464 | 26,07 | 40,00 |
| 7 | 812 | 29,20 | 39,69 |
| 10 | 1160 | 22,95 | 39,51 |

Число блоков и общий бюджет меша сохраняются на четырёх сидах 42, 7, 8191 и 23011. В таблице ширина и просвет взяты по наихудшему результату среди этих сидов. Все оболочки замкнуты, каждое ребро имеет две ориентированные в противоположные стороны грани. Габариты каменных блоков попарно разделены в плане. Пересечение каждой грани с проекцией треугольников крыши проверено отсечением полигонов. Выходов сквозь плато нет. Внешние кромки сугробов утоплены в исходный рельеф минимум на 0,14 единицы. Снежные грани на скале имеют положительную вертикальную составляющую нормали выше 0,58. Повторное построение тем же сидом даёт те же данные. [Проверка и результаты по каждому сиду](geometry.json).

У входа заменяется первая группа скал нижнего яруса. Меш плато, сама кромка, проход и размещение деревьев используют исходную геометрию. Камень использует игровой материал из `src/world/cliffs.ts` с плоскими нормалями, шероховатостью 0,93 и металличностью 0. Снег использует материал площадки. Снежные шапки и каменные грани имеют общие вершины по границе, по одному материалу на треугольник.

## Кадр, снег и тени

Видимые снежные грани занимают 26,83%, 24,36% и 24,83% площади самой боковины при 4, 7 и 10 округлых блоках соответственно. При добавлении видимых сугробов у основания в числитель и знаменатель доли составляют 31,34%, 31,02% и 31,83%. Измерения сделаны на сиде 42 по ID материалов с проверкой глубины. [Полные замеры обоих семейств](../integration/final-walls/report.json).

Исходная стенка интеграции совпала с архивной базой `f79fcb7` во всех 360 000 пикселях. У активных пресетов изменилась падающая тень у подножия. В итоговых кадрах сохранено штатное освещение, поэтому требование побитового совпадения вне силуэта при включённой тени не выполнено.

| Семейство | Пресеты | Отличий за границей проекции с тенями, пиксели | Отличий за границей без теней, пиксели |
| --- | --- | --- | --- |
| Округлые блоки | 4 / 7 / 10 | 775 / 1210 / 1286 | 0 / 0 / 0 |
| Угловатые глыбы | 5 / 8 / 12 | 1284 / 1318 / 974 | 0 / 0 / 0 |

На исходной стенке проверка самого контрольного режима зарегистрировала изменение 38 299 пикселей при отключении приёма теней. Дополнительный сид 23011 снят со средней плотностью каждого семейства. [Округлые блоки](../integration/final-walls/rounded-1-23011.png) · [Угловатые глыбы](../integration/final-walls/angular-1-23011.png).

## Стык снега и камня в движении

На сиде 42 камера прошла одну дугу у обоих средних пресетов. Снято по семь кадров при азимутах от −129° до −105° с шагом 4° и при возвышении 13°. Азимут отсчитан от мировой оси +Z в сторону +X. В каждой позиции используются один радиус 245 и вертикальный угол обзора 27°. При возврате к −117° каждый пресет повторил исходный кадр побитово. [Последовательности и увеличенная деталь](seams.jpg) · [Координаты камеры и проверки RGB](seams.json).

У семи округлых блоков на проверенной грани видимый контур шапки непрерывен во всех семи ракурсах. У восьми угловатых глыб внешняя граница также сохраняет форму, но по внутренней диагонали одной шапки виден меняющийся с углом пунктир из серых пикселей. Он сохраняется и при отключённом приёме теней. На этих последовательностях не видно сквозного просвета или переключения целой грани между снегом и камнем. Прогон выполнен на Chromium с программным WebGL SwiftShader; устойчивость шва на целевом GPU не проверена.

## Как повторить проверку

В корне интеграционной ветки с установленными зависимостями выполните команды ниже. Если контрольные PNG нужны повторно, запустите Vite на порту 5173 и выполните первую команду со сценой в Chromium. Для последней команды нужен Python с Pillow и шрифт DejaVu Sans. Наборы кадров создаёт [скрипт съёмки](../integration/capture-walls.cjs).

```sh
node docs/mountains-slice/wall-rounded/capture-without-shadows.cjs \
  http://127.0.0.1:5173 /tmp/mountains-wall-control all
node experiments/plateau/slice-wall-rounded.test.cjs
node docs/mountains-slice/wall-rounded/project-footprint.cjs /tmp/mountains-wall-footprints
python docs/mountains-slice/wall-rounded/compare_views.py \
  docs/mountains-slice/integration/final-walls /tmp/mountains-wall-footprints \
  /tmp/mountains-wall-comparison \
  --no-shadows /tmp/mountains-wall-control \
  --base docs/mountains-slice/integration/baseline
```

При построении маски скрипт проецирует все треугольники удалённой и добавленной геометрии через штатную камеру. Невидимые треугольники включены. Границу проекции он расширяет на два пикселя для сглаживания. Сравнение учитывает любое побитовое отличие по RGB за этой границей. [Результат независимого сравнения](outside-wall.json).

Для последовательностей крупных планов и независимого кадра без теней используйте тот же запущенный сервер.

```sh
node docs/mountains-slice/wall-rounded/capture-seams.cjs http://127.0.0.1:5173 /tmp/mountains-seam-frames
node docs/mountains-slice/wall-rounded/capture-seams.cjs http://127.0.0.1:5173 /tmp/mountains-seam-frames shadow-control
python docs/mountains-slice/wall-rounded/make-seam-sheet.py /tmp/mountains-seam-frames /tmp/mountains-seam-sheet
```
