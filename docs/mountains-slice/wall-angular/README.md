# WB · Угловатые глыбы у подъёма

На нижнем ярусе три пресета обвала по листам 13–15. У каждой глыбы свой замкнутый объём, косой гребень и наклонные верхние грани. Лежащие рядом снежные пятна соединяются по общему ребру. Камень и снег используют материалы сцены.

## Открыть срез

На ветке `integration/mountains-1` выполните `npm ci` и `npm run dev -- --host 127.0.0.1`. Откройте `/experiments/plateau/mountain.html?wall=angular&preset=1&seed=13947` на адресе Vite, затем нажмите «Боковина у подъёма». Параметр `preset` принимает 0, 1 или 2 для 5, 8 и 12 глыб соответственно.

## Проверка геометрии

Из корня ветки `track/wall-angular` выполните `node experiments/plateau/slice-wall-angular.test.cjs`. Последний сид можно передать первым аргументом. Перед проверкой нужны зависимости из `npm ci`.

Каждый из трёх пресетов проверен для 13947, 42, 7, 8191, 23011 и 818723. Повторная генерация с тем же сидом даёт одинаковые буферы. У каждой глыбы замкнутый меш с согласованным направлением треугольников. Глыбы стоят на грунте, их границы в плане разделены, верхние вершины лежат ниже кромки плато. На ширине участка 100 наибольшая ширина одной глыбы составляет 32,55. Минимальный зазор от проверенных вершин до края полосы подъёма составляет 38,85 в координатах нижнего яруса.

Все треугольники снежных пятен обращены вверх. Для центра каждого треугольника пущен луч вниз. Наибольшее расстояние до несущей поверхности камня составляет 0,0551. Детальные значения для всех восемнадцати комбинаций приведены в [geometry.json](geometry.json).

## Снег на боковине

При генерации запас снега на наклонных гранях зависит от высоты гребня, экспозиции ветру и уклона плоскости. Для фиксированного направления от входа генератор выбирает границу снежных пятен по видимой площади камня. Геометрия остаётся постоянной при перемещении игрока.

Независимая пиксельная проверка использует полную проекцию исходной камеры 800×450 и отдельные идентификаторы для видимого камня, снега поверх него и сугроба у подножия. На сиде 42 пресеты 5/8/12 дали 25,7%, 25,5% и 23,4%. На всех 18 комбинациях диапазон составляет 23,4–26,4%. В этом замере участвует только новая геометрия. Остальные объекты, материалы и тени входят в общую проверку сцены на интеграционной ветке. [Все замеры](projection.json) · [Проверочная проекция](projection.jpg)

## Тёмная плита на архивном кадре

Четыре луча в центральную часть плиты пересекли `flank`, исходную боковую поверхность выреза подъёма из `buildWedgeAscent(...).cut.flank`. Например, координата (870, 450) в полном кадре 1440×780 попадает в треугольник 105214. На левой границе плиты луч из (800, 460) попадает в соседнюю декоративную поверхность скал. Луч из (780, 520) попадает в переднюю глыбу. Это проверено на геометрии нижнего яруса базы `f79fcb7` с камерой архивной съёмки. [Камера и попадания лучей](slab-rays.json)
