# Срез подвесного моста

Ветка `track/bridges`, база `f79fcb7`. Отдельный эксперимент собирается в общей сцене из ветки `integration/mountains-1`. Чтобы пройти от спавна, откройте `/experiments/plateau/route.html?seed=42&wall=rounded` на локальном сервере Vite. До моста можно подняться на нижний жилой ярус главной горы по склону или канату. У восточного края находится переправа на нижний ярус соседней горы.

| Критерий B | Результат и доказательство |
|---|---|
| Выбор пары | PASS на сидах 42, 7, 8191, 23011. Генератор берёт посадки у двух доступных ярусов разных гор. Пробует смещения вдоль кромки. Закрытые площадки и точки одной горы отсекаются. Расстояние для среза измерено по фактическим кромкам. Решение о пределе для других карт остаётся у владельца. |
| Конструкция | PASS. На двух берегах стоят парные стойки, между ними идут боковые канаты, подвески и поперечный деревянный настил. Провис 1,76 м, ширина настила 2,4 м, просвет под серединой 12,24 м. Три камеры приведены ниже. Визуальный выбор остаётся у владельца. |
| Достижимость | PASS. Пространственный обход с метровым шагом от реального спавна учитывает уровни опоры и стволы. На всех четырёх сидах он достигает жилой площадки по мосту. Без настила маршрут исчезает. В отдельном прогоне физики персонаж при попытке перейти без моста падает на дно и останавливается перед противоположной стеной. |
| Переход игрока | PASS. Контроллер Rapier прошёл настил в обе стороны на каждом сиде. В середине луч от головы попал именно в настил, минимальный просвет 1,729 м. В общем браузерном прогоне от спавна на сиде 42 игровой Player дошёл через стенку, тупик, канат и пещеру до соседнего плато. Использованы клавиатура Playwright, управляемый угол обзора и фиксированные шаги физики. Положение персонажа за весь маршрут задаёт физика. [Трасса общего маршрута](../integration/seed-42/metrics.json) · [Кадр от первого лица](../integration/seed-42/05-bridge.jpg). |
| Камень и деревья | PASS в данном срезе. Генератор проверяет нижнюю поверхность настила поперёк по пяти линиям с продольным шагом до 0,30 м между посадками. Для деревьев учитывает ствол и полный радиус кроны. Подставленная высокая скала или дерево посередине закрывает все варианты. Локальная преграда у одной кромки переносит посадку в свободную часть. |

## Масштаб и стоимость

Между отвесами 30 м. На каждом берегу 1 м настила опирается на площадку. Для этих гор предлагается временный максимум 32 м между посадками. Обобщение на другие расстояния и горы потребует решения владельца.

Старая плоская переправа из `experiments/mountains/crossing.ts` состояла из 12 треугольников. В актуальном стенде замеряли одну и ту же сцену с выключенной и включённой группой моста. Во всех четырёх случаях переправа добавила 4 588 видимых треугольников и три команды отрисовки. У отдельного коллайдера 218 треугольников.

| Сид | Треугольники без моста → с мостом | Медиана кадра без моста → с мостом, мс |
|---|---:|---:|
| 42 | 33 954 → 38 542 | 1 028,0 → 507,6 |
| 7 | 32 280 → 36 868 | 314,2 → 337,9 |
| 8191 | 31 756 → 36 344 | 283,3 → 245,5 |
| 23011 | 30 093 → 34 681 | 424,5 → 406,5 |

Для каждого состояния использованы четыре кадра прогрева и 12 замеров профиля при 960×540 в SwiftShader с синхронным чтением пикселя. Из-за совместной нагрузки программного рендера времена менялись даже внутри серии. Рабочее предложение по геометрии одного такого моста — до 4 588 видимых треугольников, три команды отрисовки, 218 физических треугольников. Бюджет времени для игрового GPU остаётся открытым до измерения на целевом оборудовании.

## Повторить

Из корня checkout общей сцены выполните команду запуска.

```sh
npm run dev -- --host 127.0.0.1 --port 5184
```

Для повторения проверок откройте второй терминал в том же каталоге.

```sh
node experiments/plateau/slice-bridges.test.cjs
CHROMIUM_PATH=/usr/bin/chromium node experiments/plateau/slice-bridges.capture.cjs
```

Путь к Chromium нужен при использовании системного браузера. При установленном Chromium Playwright переменную можно опустить.
