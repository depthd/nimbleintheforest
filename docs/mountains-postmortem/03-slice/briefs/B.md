# Направление B

Ветка `track/bridges` от `f79fcb7`. slice-bridges*, отчёт bridges/.

## План

Измерить разрыв между пригодными кромками. Построить береговые посадки, провисающий настил и канаты. Проверить просвет, посадки, путь в обе стороны и недостижимость спутника при снятом мосте.

## Поручение

**Задача:** навесные мосты между жилыми ярусами разных гор строятся автоматически. Часть гор достижима только по мосту: залезаешь на одну гору, переходишь мост и оказываешься на другой, на которую иначе не попасть.

**Готово, когда:**

1. Мост строится автоматически между доступными ярусами двух гор в разумной дистанции. Дистанцию определи по реальному масштабу сцены и предложи мне, число не придумывай.
2. Выглядит подвесным: два якоря на кромках плато, статичный провис по центру, настил и канаты, PS1-стиль. Заглушки не соединяются.
3. На 3+ сидах есть гора, достижимая только по мосту. От точки появления до неё есть полный путь (обход графа): мостовых гор без пути, то есть софтлока, нет.
4. Игрок переходит мост обычным вводом, не проваливается и не застревает, камера не пробивает настил.
5. Мост не пересекает скалу и деревья.

**Не-цели:** раскачивание, физика, разрушение, лут на мостах.
