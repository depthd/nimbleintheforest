# Разработка игры

- Новую работу начинайте от свежей основной ветки (`origin/HEAD`). Перед изменениями проверьте `git status --short --branch` и выполните `git fetch origin`.
- Для параллельной работы используйте короткоживущие ветки или отдельные worktree. Заранее распределите общие файлы. Изменения возвращайте в основную ветку через pull request.
- Игра запускается из `index.html` и `src/main.ts`. Диагностические режимы включаются параметрами URL. Модели находятся в `public/models/`, сборка и результаты тестов остаются локальными.
- Перед слиянием проверьте актуальную базу, сборку и затронутую механику. Выпуск на GitHub Pages выполняйте отдельным действием по одобрению владельца игры.

Команды разработки и проверки приведены в [README](README.md). Процесс выпуска описан в [рабочем процессе](docs/WORKFLOW.md).
