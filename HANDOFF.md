# Передача чата: горы nimbleintheforest

**Состояние на 22 ноября 2026 года, Самара.** Это сохранённый WIP задачи PLATEAU-001. Пользователь остановил работу после того, как попросил самостоятельно искать лучшую крупную форму. Код локальной пробы зафиксирован в состоянии на момент остановки.

## Цель и оценка пользователя

Нужна гора, которую интересно исследовать: крупный читаемый силуэт, неровные скальные массы, просторные уровни, открытый извилистый подъём и настоящая тупиковая пещера. Эталон **F** из первоначального сравнения A–F удачен для снежной кромки вблизи. Пользователь прямо отверг вид полной горы издали. На общем плане видны сплошная стена, регулярные горизонтальные ряды и рябая снежная крышка. Дальние и средние кадры важны для оценки крупной формы. Три отложенных эксперимента с ломаной, ступенями и дугами пересматривать по этой передаче не требуется.

## Что сохранено

- Основа снимка — `4d739f142d67455dda774770894c0f3080406175`, ветка `task/PLATEAU-001-camera`. Код ранее снятой полной горы — `18ac137a9cc9947afc4eecfd1e830893b495284f`, исторический QA — `db4edad95c9dc2c916ff61bb11e66a88bc2661e7`. Первоначальный F — `9462b0b498b89ec0932f536140378b6c821cc6aa`.
- Первая локальная проба убрала регулярные ряды, добавила несколько десятков крупных выступов и разный рельеф верха. Исполнитель отбраковал её по дальнему кадру: гора всё ещё похожа на крышку на столбах.
- Последние локальные правки увеличили перепады высоты, изменили нависание и сделали выступы шире у основания. Работа остановлена до итоговых кадров и проверки. Оценки пользователя этой пробы не было.
- Базовая сцена находится в `experiments/plateau/mountain.html`. В WIP режим `?legacy=1` открывает предыдущую полную гору, а `wedge-snow.html?variant=F` — первоначальный ближний ориентир.

Исторические ветки `archive/mountains-2026-11-10-failed` и `archive/mountains-2026-11-10-landmarks-deferred` нужны как справка, их изменения в WIP не объединены.

## Как воспроизвести

После `npm ci` из корня репозитория:

```sh
npx tsc --noEmit -p experiments/plateau/tsconfig.json
node --max-old-space-size=10000 experiments/plateau/mountain.test.cjs
MOUNTAIN_LEGACY=1 node --max-old-space-size=10000 experiments/plateau/mountain.test.cjs
npm run dev -- --host 127.0.0.1 --port 5235
```

Страница `http://127.0.0.1:5235/experiments/plateau/mountain.html`. Съёмка требует доступного Node-модуля `playwright` и браузера `/usr/bin/chromium`:

```sh
VIEWS=overview,back,ascent,edge node experiments/plateau/mountain-capture.cjs http://127.0.0.1:5235/experiments/plateau/mountain.html /tmp/mountains-qa
```

## Известные проблемы и границы проверки

- На первой локальной пробе контрольный луч назад из пещеры не подтвердил прежние **9 м** до задней стенки. Причина не установлена. Финальная локальная правка осталась без завершённой геометрической проверки; кадры первой пробы к ней не относятся.
- Сохранённый PASS полной горы `18ac137` относится к её снежной оболочке, контрольным лучам, компиляции и браузеру. Художественная приёмка, сплошная проверка пересечений, физика персонажа, полный игровой подъём и аппаратная производительность в этом PASS не покрыты.
- На прежней полной горе оставались регулярные ряды, выступ у подножия подъёма и мелкие тёмные точки на переходах. Последний зафиксированный опубликованный source тестовой сцены — `8b2652a476649fbb80cbfe8fdfcc2b3febfe361d`; состояние сайта в рамках сохранения не перепроверялось.
- Коммиты ветки фиксируют данные и документы. Тесты разработки при переносе не перезапускались.
