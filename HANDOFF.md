# Исследование производительности Nimble in the Forest

Снимок работы одного чата от 22 ноября 2026 года. Исследование проведено на базе `e17417d059d4bf6e096ec6e059de769f71a71914` в `depthd/nimbleintheforest`. Цель состояла в том, чтобы найти ускорения без заметного изменения картинки и механики, учитывая уже существующие Worker рельефа, instancing леса, объединение статических объектов и кэши.

## Что сделано

- Замерены старт и прогретая production-сборка в доме, лесу, на открытом обзоре, в метели, при скоплении предметов и рубке. Сохранены профили CPU, результаты чтения кадров WebGL, сравнения пикселей и данные для воспроизведения.
- Чтение снежных плиток за один проход (`831058908824abdd6b4150e0d6273a0554f66e55`) снизило медиану времени CPU-кадра при ходьбе в метели с 10,5 до 9,5 мс и p95 с 27 до 23 мс. Рендеринг в этом замере отключён. Пройдены 900 точных сравнений текстур, границ и видимости, включая погоду, смену покрытия и архивные плитки.
- Переиспользование тепловых агрегатов (`f5c21491d981afe5f81d28543df5156e68fdb6e7`) дало 5–8% на измеренном участке теплового расчёта. Ускорение всего кадра не подтверждено. Графические варианты не дали устойчивого ускорения на доступном программном SwiftShader.
- Вторая серия остановлена по просьбе пользователя. Проба с быстрым отсевом для прямоугольных укрытий (`45f780afce3dbba7dd9797ab191bb6272ac25865`) собрана. Пройдены существующие тесты покрытия и 600 000 сравнений результата с базой. Парный замер прерван до получения результата, прирост неизвестен.

## Как проверить и восстановить

Из корня клона после переключения на `wip/perf-research-chat01`:

```sh
snapshot=docs/qa/PERF-RESEARCH-20261116/e17417d059d4bf6e096ec6e059de769f71a71914/wip
(cd "$snapshot" && sha256sum -c research.zip.sha256)
git bundle verify "$snapshot/all-research-refs.bundle"
git fetch "$PWD/$snapshot/all-research-refs.bundle" 'refs/heads/task/*:refs/remotes/perf-snapshot/*'
git log -1 refs/remotes/perf-snapshot/PERF-RESEARCH-20261116
```

Так варианты будут доступны через `refs/remotes/perf-snapshot/`, сохраняя исходные SHA и локальные ветки. Достаточно иметь базовый коммит в клоне. Восстановление всех 12 ссылок и совпадение их SHA проверены в отдельном клоне.

Для просмотра отчёта распаковать `research.zip` в отдельный каталог и открыть `report/report.pdf` или `report/report.html`. `HOWTO.txt` содержит последовательность запусков. Замеры делались с Node 24.22.1, Chromium 156.0.8078.79, Playwright и зависимостями из `package-lock.json` базы. Графический режим был 640×360 и DPR 1. Для проверки сборки снимка достаточно `npm ci`, `npm run build` и `npm run test:snow-cover`. Для исходниковой проверки второй серии использовать `additional-materials/round2/cover-compare.cjs`. Скрипту нужен `RESEARCH_ROOT` с каталогом `repo` на SHA пробы или этой ветке и каталогом `baseline` с исходниками базы. В `repo/node_modules` должны быть установлены зависимости.

## Что осталось и от чего зависит

- Парный замер второй серии и проба повторного использования данных поверхности с пересчётом при изменении укрытий не закончены. Вариант с Worker для погодной пересборки следов описан как гипотеза. Он не реализован.
- Совместный эффект вариантов снега и тепла не измерялся. Для оценки графики и движения требуется прогон на аппаратной видеокарте. FPS SwiftShader непоказателен для игрока.
- Другие чатовые задачи для восстановления не нужны. При отборе в общую интеграцию сверить пересечения с изменениями снега, тепла и рельефа после указанной базы. Собирать следует выбранные исходниковые патчи с проверкой итогового SHA.
